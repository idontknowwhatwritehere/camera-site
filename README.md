# Rapid Cortisol: приложение

Адрес: https://app.vi-anhim.online/  
Сайт проекта: https://vi-anhim.online/

Статическое приложение: `index.html`, `app.css`, `app.js`. Обработка изображений выполняется в браузере.

GitHub Pages публикует корень ветки `main`. Домен указан в `CNAME`.
